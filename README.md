# Sales Performance Dashboard (Power BI)

A multi-table Power BI report built from raw sales data, designed as a 3-page story: start with the big picture, then drill into products and customers.

## What's inside
- **Page 1 — Overview**: total sales, profit, and orders at a glance, with a monthly trend
- **Page 2 — Product performance**: which products and categories are driving (or dragging) results
- **Page 3 — Customer behavior**: repeat customers, order frequency, and top segments

## Dataset
Sales, products, and customers tables (multi-table relational structure, not a single flat file).

## Tools
Power BI (data modeling across multiple related tables, DAX, Power Query, multi-page report design)

## What I learned
- How to design a report that tells a story page by page instead of putting every chart on one screen
- Why a clean data model (proper relationships, no duplicated tables) matters more than any single DAX formula
- How to track product performance, monthly trends, and customer behavior side by side without the report feeling cluttered

## How to view it
Download the `.pbix` file and open it in Power BI Desktop (free, Windows only) to interact with the full report.
